2 · Put it in the game

  1. In Steam, right-click Cookie Clicker → Manage → Browse local files.
  2. Open resources → app → mods → local.
  3. Extract the zip there. You should end up with mods/local/MyCookie/info.txt and main.js next to it.
  4. Start the game, go to Options → Mods, make sure your mod is turned on, then restart the game.
Can't download? Make the two files by hand
